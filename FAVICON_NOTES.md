# Favicon

Brand favicon for Sapphire Consulting using the corporate blue emblem on a deep navy rounded square.

## Included
- `public/favicon.ico` — multi-size browser favicon
- `public/icons/icon-16.png`
- `public/icons/icon-32.png`
- `public/icons/icon-48.png`
- `public/icons/icon-192.png`
- `public/icons/icon-512.png`
- `public/icons/apple-touch-icon.png`
- `public/favicon.svg`
- `public/site.webmanifest`

The root `app/layout.tsx` references the favicon and manifest through Next.js metadata.
